## Внедрен self-learning loop для Codex

После обсуждения автоматического Obsidian sync добавлено правило в глобальный Codex context и проектный `AGENTS.md`.

Файлы:
- `/Users/dima/.codex/AGENTS.md`
- `/Users/dima/Downloads/Projects/Платиненталь 2/AGENTS.md`

Суть правила:
- Obsidian sync теперь event-based, а не после каждой правки;
- daily note — для raw observations и короткого лога;
- `MEMORY.md`/`knowledge/` — только для validated source-of-truth;
- `AGENTS.md`/skills — только для behavior rules, которые агент должен выполнять автоматически;
- адаптация Karpathy loop: один editable surface, понятный signal/metric, timebox, минимальная правка, promote только validated learnings.

Источник идеи: Karpathy/autoresearch — агент меняет один файл, запускает фиксированный эксперимент, сравнивает метрику, оставляет или откатывает изменение. Для Codex это адаптировано без бесконечных автономных экспериментов: обучение происходит на реальных сбоях, пользовательских поправках и проверяемых workflow.

## Правило по отзывам врачей

- Принято новое правило для клиентских прототипов врачей: отзывы можно брать с любых проверяемых публичных площадок и из любых городов, если отзыв персонально относится к врачу.
- География отзыва и клиника, где был оставлен отзыв, больше не являются причиной исключать его из клиентского прототипа.
- В клиентских `.md` убраны формулировки «московский контекст», «внешние места приема», «нужен отдельный допуск», «лучше не использовать» применительно к персональным отзывам.
- Ограничение остается редакционным: площадка, дата, корректное сокращение, отсутствие обещаний результата и запрет на «лучший», «золотые руки», «без осложнений», «гарантированный результат».

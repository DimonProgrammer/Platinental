# Платиненталь — CLAUDE.md

## Проект

Платиненталь — клиника пластической хирургии и косметологии в Казани (kzn.platinental.ru).
Пересборка сайта с нуля: быстрый, рекламно-оптимизированный лендинг под Яндекс Директ.
Три направления: Пластика, Косметология, Космецевтика. Аудитория: премиум-сегмент, Казань.

**КЛЮЧЕВОЙ ФАКТ (подтверждено клиентом, 2026-04-20):** Platinental Казань — самостоятельная клиника пластической хирургии в Казани. Отдельное юр. лицо (ООО «Платинентал Казань»), НЕ филиал, НЕ американский/международный бренд. С московской клиникой Platinental общего только один из учредителей (Андрей Искорнев оперирует в Москве и Лос-Анджелесе — это отдельные проекты). Часть врачей пересекается с другими клиниками, часть — только казанские. У каждого хирурга клиники своя школа и авторские техники — «клиника работает по методике Искорнева» писать НЕЛЬЗЯ. Искорнев упоминается ТОЛЬКО в статусе «один из учредителей и идейный вдохновитель». Позиционирование: казанская клиника премиум-сегмента. Членство хирургов в ASPS/ISAPS/IPRAS и обучение за рубежом — личные квалификации конкретных врачей, не признак «международной сети». Сайт — только Казань.

**НИКОГДА не писать:**

- «американский бренд», «международный бренд», «филиал»
- «4 города», «Москва·Алматы·Астана» как наши локации
- конкретное число врачей в копирайте (~~«8 хирургов»~~ — команда меняется, не акцентируемся; указывать количество только там, где оно рендерится из `src/data/doctors.ts`)
- «у Мамедова патент», «авторская методика Васильева» на общих страницах — авторские методики и патенты отдельных врачей указываем ТОЛЬКО на страницах этих врачей. На общих разделах — обезличенно («у наших хирургов есть авторские методики и патенты»).

**Визуальная идентичность — принципиально отличается от московского `platinental.ru`:**

- У москвичей: тёмный фон, красные акценты, «мужская» драматическая эстетика Искорнева.
- У нас: **светлая премиальная эстетика** — cream `#FFFDF8`, чёрный только в тексте, champagne `#C4A882` акцент. Никакого красного, никакого тёмного фона как доминанты. Лёгкая, воздушная, «эстетическая».
- Логотип и шрифты можно частично переиспользовать (они у бренда общие). Фоны, цвета, тональность — свои.

**Стек:** Astro 5 + TailwindCSS v4 + TypeScript | Хостинг: Beget Cloud или Timeweb Cloud (российский, 152-ФЗ) | Аналитика: Яндекс.Метрика (`astro-ym`) | Реклама: Яндекс.Директ (команда New Age: Александр + Андрей)

## Design System

Стиль: функциональный минимализм, премиальная медицинская эстетика.

- Палитра: cream `#FFFDF8` / black `#0A0A0A` / champagne `#C4A882` (акцент, pending client sign-off)
- Шрифты: **Cormorant Garamond** (display) + **Golos Text** (body), подключены через Google Fonts с cyrillic subset
- **ЗАПРЕЩЕНО:** яркие цвета, стоковые фото, перегруженные макеты, красный акцент, градиенты как background
- **ОБЯЗАТЕЛЬНО:** перед любым UI/дизайн-кодом → читать в порядке приоритета:

## Visual Development Block (МАНДАТОРНО после любого frontend-изменения)

Claude не видит глазами. Любое изменение UI/компонентов/стилей ДОЛЖНО быть визуально проверено через Playwright MCP прежде чем заявлять "готово".

**Протокол:**
1. Убедиться, что dev-сервер запущен (`npm run dev` → http://localhost:4321).
2. Navigate → `browser_take_screenshot` на 3 вьюпортах: **1440×900** (desktop), **1024×768** (tablet), **375×812** (mobile).
3. Сохранять в `.playwright-mcp/<feature>/` — именно как baseline для визуальной регрессии.
4. `browser_console_messages` level=error → ожидаем 0 ошибок. Любая ошибка = fail.
5. Сверить с `DESIGN.md` + `docs/design-direction.md` — никаких запрещённых цветов/шрифтов/градиентов.
6. Для серьёзного ревью → дёргать subagent **design-reviewer** (`.claude/agents/design-reviewer.md`): он гонит весь чеклист в Haiku-модели и возвращает findings с file:line.

**Если Playwright MCP недоступен** — не утверждать "готово". Сказать явно: "не смог визуально проверить, нужна ручная проверка на экране".

**Никогда** не пропускать визуальную проверку из-за "это маленькое изменение". Мелкие правки тоже ломают layout.

## Workflow

### Принципы

- Всегда использовать Context7 MCP для документации библиотек/фреймворков — без ожидания явного запроса
- Один чат = одна задача. Не смешивать контексты
- Нетривиальная задача → Plan Mode сначала
- Контекст в файлах (knowledge/, CLAUDE.md), НЕ в голове
- Кодинг → `/ship`. Некодинг → предложить отметить в TickTick
- Что-то идёт не так → остановиться и перепланировать, не давить дальше
- После завершения задачи → запустить typecheck, тесты и lint перед тем как считать готовым

### Поведение Claude (авто)

- Начало сессии без задачи → проверить TickTick и предложить что делать
- Начало сессии с задачей → работать сразу, не отвлекать
- Задача завершена → предложить отметить в TickTick
- Пользователь упоминает новую задачу → предложить добавить в TickTick
- Большая задача → предложить разбить на подзадачи (checklist)
- Много переключений контекста → мягко предложить новый чат
- **Kaizen:** замечай неэффективности. Формат: `Kaizen: [наблюдение] → [предложение]`. Макс 1 за ответ

### Obsidian Vault Commands

Папка `daily/` — daily notes в формате `YYYY-MM-DD.md`. Markdown-файлы: `[[double brackets]]` для ссылок.

**Авто-запуск (Claude запускает сам):**
- Утро (первая сессия дня) → `/today`
- Конец дня ("всё", "хватит", "закругляюсь") → `/closeday`
- После созвона/встречи (пользователь скидывает заметки) → создать daily note, предложить `/graduate`

**Авто-предложение:**
- Перед стратегическим решением → `/challenge [тема]`
- При обсуждении двух разных тем → `/connect [A] [B]`
- Раз в неделю (понедельник) → `/schedule` и `/drift`
- При упоминании "идея", "а что если" → предложить записать в daily note
- Накопилось 7+ daily notes → `/graduate`
- Пользователь застрял → `/ideas`

## Decisions

- **Стек: Astro 5 + TailwindCSS v4** (апрель 2026) — статический сайт с 0 KB JS по умолчанию. 95+ Lighthouse. Лучший выбор для 55+ страниц с контентом. Astro-острова для форм и WhatsApp-кнопки.
- **Хостинг: Beget Cloud или Timeweb Cloud** (апрель 2026) — только российские ЦОД (152-ФЗ). Beget = выше производительность, Timeweb = проще управление.
- **Максима нет в проекте** (апрель 2026) — удалён из команды.
- **Дизайн + разработка = пользователь + Claude** (апрель 2026) — весь цикл: дизайн, Astro + Tailwind, контент, запуск.
- **Воркфлоу:** Claude помогает с дизайном (Pencil MCP / Figma), кодом (Astro), копирайтингом, тестированием.
- **Копирайтинг:** информационный стиль (Ильяхов/Главред) + JTBD-месседжи. Система промптов → `docs/copywriting-prompts.md`.
- **Wireframes в Pencil MCP** (апрель 2026) — 3 фрейма: главная, страница услуги, лендинг Директ. Переданы Максиму как визуальное ТЗ.
- **Корл — партнёр-конкурент** (апрель 2026) — Платиненталь арендует ОЗ у Корл. Не афишировать, нет прямых ссылок.
- **Акцентный цвет TBD** — не красный (клиент подтвердил). Кандидаты: тёмное золото `#B8956A`, шампань `#C4A882`. Согласовать с клиентом.

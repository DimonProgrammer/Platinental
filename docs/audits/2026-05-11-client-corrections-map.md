# Карта точечной проверки клиентских правок

Документ нужен для ручной приемки: открыть нужную страницу сайта, найти указанный блок и проверить, как внесена каждая правка из Notion/Telegram, транскриптов созвона 7.05 и подтверждений от 8.05.

## Источники

- Notion/Telegram export: `Notion выгрузка/ExportBlock-04f48e40-0924-46ec-9324-417eccffb488-Part-1/Задачи из Telegram cacf1bbf7a774f159639b21db84ff05e_all.csv`
- Вложенные задачи: `Notion выгрузка/.../Задачи из Telegram/*.md`
- Созвон: `Созвон с клиентом 7.05/transcripts-v2-gigaam/`
- Спорные места и ответы: `Созвон с клиентом 7.05/transcripts-v2-gigaam/unclear-moments.md`
- Подтверждения: `knowledge/call-2026-05-07-confirmations.md`
- Рабочий PRD: `docs/prd/2026-05-08-call-site-changes.md`
- Служебная web-карта: `/review/2026-05-08`

## Как пользоваться

1. Открыть страницу из колонки `Где проверить`.
2. Найти блок из колонки `Блок/место`.
3. Сверить с колонками `Как должно быть` и `Как не должно быть`.
4. Вручную отметить, если реализация визуально/смыслово не совпадает.
5. Если статус `не внедрять без подтверждения`, не считать это багом сайта: это клиентский пункт, который намеренно удержан до подтверждения.

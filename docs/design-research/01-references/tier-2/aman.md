# Aman Resorts — aman.com

**Captured:** 2026-04-27, 1440 (single viewport)
**Compass-rating:** 3/5 (для section transitions и pacing)

## Что увидено

Aman = «**art of silence**». Главная страница 4573px, около 8-10 секций. Каждая — **single image + small caption + Reserve link**. Очень sparse. Брeath между секциями — vertical gap ~200-300px чистого whitespace без content.

Визуальное ощущение — это **тихий buying-journey**, не storytelling. Image-led, текст минимальный, всё ведёт в booking flow.

## Tokens

- **Display: Lyon Display Web (humanist serif с ярким contrast strokes)**. Размер H2 = 31px, weight 400. Letter-spacing 0.5px.
- **H3 — Lyon Text Web 19.6px, letter-spacing 0.98px (0.05em)**.
- **Body — WhitneySSm (sans), 10px (!), letter-spacing 2px (0.20em — extreme!)**.
- **Page bg — light cream / sand (визуально, не извлечено).**

## Что забираем

1. **«One image per scroll-stop» pacing** — для нашей главной слишком austere, но **для Concept-страницы и для отдельных treatment-spread'ов внутри plastika.astro** — отличная модель.
2. **Лeyebrow body text 10px + letter-spacing 0.20em** — это **ровно тот pattern**, который compass называет «small uppercase utility face that pins to the upper left». Aman именно это и делает: small caption → image → small caption.
3. **Vertical whitespace как актив дизайна** — секции отбиваются 200-300px чистого пространства между. У нас в прототипе секции слишком плотно одна за другой.
4. **Lyon Display Web (или free analog)** — Lyon — это Cormorant'у близкий контрастный serif, лицензионный (Commercial Type). Альтернатива: **Cormorant Garamond Italic** ровно достигает похожего эффекта.

## Что НЕ берём

- ❌ 10px body — невозможно для русской audience.
- ❌ Полный отказ от storytelling — у нас нужны принципы клиники, врачи, отзывы.
- ❌ Booking-only CTAs — у нас broader funnel.

## Применимость

Aman = **pacing reference**. Берём:
- vertical breathing room 200-300px между секциями (sectionsmedium / deep-breath gaps);
- one-image-per-scroll-stop для concept-страницы;
- small uppercase utility caption tactic.

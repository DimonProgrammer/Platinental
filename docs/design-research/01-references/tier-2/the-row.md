# The Row — therow.com

**Captured:** 2026-04-27, 1440 (single viewport)
**Compass-rating:** 4/5 (calibration для quietness)

## Что увидено

The Row главная — это **gallery-not-store** в чистом виде. **Только две фотографии** на 1440×1870 страницы, обе close-up B&W (рукав-пуговица, ремень-пряжка). Нав минимальный (Women, Men, Handbags, Home, Collections, Galerie слева — Search, Stores, Login, Bag справа). Wordmark THE ROW в центре header — letter-spacing wide, weight regular. Нет CTA. Нет product cards. Нет prices. Это коллекционный buyer site.

## Tokens

- **Single font family**: Basic Commercial (humanist sans). 13px везде, weight 400, letter-spacing normal.
- **Pure B&W palette**: white bg, ink #000 для wordmark, #1C1B1B (rgb 28,27,27) для links.
- **Page-height 1870px** — что то близко к Byredo (single-screen+).

## Что забираем

1. **«Two-photo art-gallery» pattern** — для нашей **Concept-страницы** или для отдельной brand-page «Pursuit of Quiet Confidence». Два close-up B&W фото = весь content.
2. **Monumental restraint scaling** — **типография NEVER scaling for hero**. У них даже H2 13px. Это слишком austere для нашего, но указывает: можно делать «hero» через image scale + monumental typography в footer/header, не в центре.
3. **Wordmark THE ROW в header center** — wide-tracked, regular weight, как floating marker. Близко к Maison Sisley monument.

## Что НЕ берём

- ❌ Pure B&W без cream — не наш палитра.
- ❌ Single-product-no-CTA homepage — мы не art-gallery, нам нужно вести user в направления.
- ❌ 13px body — слишком мелко для нашей audience.

## Применимость

The Row — **calibration point** для дисциплины. Он показывает, насколько austere можно. Мы должны находиться **между Bader и The Row** — editorial с substance, но без overload.

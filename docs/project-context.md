## Как работает клиент
- Не любят созвоны — общение в мессенджерах
- Маркетолог не разбирается → бриф заполняем сами, клиент корректирует

## Рабочий процесс

### Этап 1: Архитектура и бриф
1. Подготовить архитектуру сайта (страницы, разделы)
2. Заполнить бриф самостоятельно
3. Согласовать с клиентом (они подкорректируют)
4. Уточнить у клиента: количество товаров в космецевтике, цветовые предпочтения

### Этап 2: ТЗ для Максима
- Передать: общее видение, примеры сайтов, цвета, структуру страниц
- Максим сам делает дизайн + верстку + прототип
- Дмитрий проверяет и направляет, не микроменеджит

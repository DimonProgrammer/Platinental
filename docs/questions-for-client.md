**Проверка 2026-05-12:** открытые источники подтверждают сам диплом и последующие периоды обучения, но год диплома не найден.

**Почему блокирует:** в блоке образования не должно быть визуальных пустых дат, но год нельзя выдумывать.

**Варианты ответа:**
- Подтвердить год диплома по лечебному делу.
- Оставить строку без года, без визуального дефиса.

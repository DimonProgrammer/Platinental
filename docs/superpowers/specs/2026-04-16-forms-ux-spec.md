## Инвентарь форм на сайте

Из PRD и архитектуры — 10 точек, где пациент должен оставить данные. Но по факту это **3 типа формы** + **1 модалка** + **2 альтернативных канала**.

---

## Типы форм (консолидация)

### Тип A — «Быстрая запись» (Quick Record)

**Где:** Hero CTA, sticky header (модалка), кнопки «Записаться к [Врачу]» на карточках врачей, CTA-блоки на /plastika/, /kosmetologiya/, /kosmecevtika/.

**Цель:** минимальное трение. Пациент уже решился — ему нужно оставить контакт.

**Поля:**

| Поле | Тип | Обязательное | Placeholder / Label |
|------|-----|-------------|---------------------|
| Имя | text | Да | «Ваше имя» |
| Телефон | tel + маска | Да | «+7 (___) ___-__-__» |
| Врач | hidden / предзаполнен | Нет | Не видим пользователю, заполняется автоматически из контекста (какого врача кликнул) |
| Согласие ПД | checkbox | Да | «Соглашаюсь на обработку персональных данных» |

**CTA-кнопка:** «Записаться на консультацию»
**Micro-copy под кнопкой:** «Перезвоним в течение часа»

### Тип B — «Задать вопрос» (Inquiry)

**Где:** Главная страница (основная форма), /contacts/ (форма обратной связи).

**Цель:** пациент ещё не готов записаться, но хочет задать вопрос или описать ситуацию.

**Поля:**

| Поле | Тип | Обязательное | Placeholder / Label |
|------|-----|-------------|---------------------|
| Имя | text | Да | «Ваше имя» |
| Телефон | tel + маска | Да | «+7 (___) ___-__-__» |
| Сообщение | textarea | Нет | «Опишите вашу ситуацию или вопрос» |
| Согласие ПД | checkbox | Да | «Соглашаюсь на обработку персональных данных» |

**CTA-кнопка:** «Отправить»
**Micro-copy:** «Ответим в течение 2 часов. Пн–вс 9:00–20:00»

**Поля:**

| Поле | Тип | Обязательное | Placeholder / Label |
|------|-----|-------------|---------------------|
| Имя | text | Да | «Ваше имя» |
| Телефон | tel + маска | Да | «+7 (___) ___-__-__» |

**Опции dropdown:**

- Пластическая хирургия — тело

- Космецевтика
- Не определился(-ась)

**CTA-кнопка:** «Записаться на консультацию»
**Micro-copy:** «Перезвоним и подберём удобное время»

## Общие UX-требования для всех форм

### Поля ввода

**Имя:**
- Минимум 2 символа
- Автокапитализация первой буквы
- Без валидации на кириллицу (могут быть иностранные имена)

**Телефон:**
- Маска: `+7 (___) ___-__-__`
- Автофокус на первую цифру после +7
- `inputmode="tel"` для мобильной клавиатуры
- Валидация: 10 цифр после +7
- Принимать форматы: 8XXXXXXXXXX, +7XXXXXXXXXX, без кода

**Textarea (сообщение):**
- Placeholder исчезает при фокусе
- Авторесайз по высоте (min-height: 80px, max-height: 200px)
- Counter символов не нужен — не ограничиваем

**Dropdown (направление):**
- Нативный select на мобайл (лучший UX)
- Кастомный на десктопе (для стилизации)
- Первая опция: «Выберите направление» (disabled, выбрана по умолчанию)

### Чекбокс 152-ФЗ

**Текст:** «Соглашаюсь на [обработку персональных данных](ссылка на PDF)»
- Ссылка открывается в новой вкладке
- Чекбокс НЕ отмечен по умолчанию (требование 152-ФЗ)
- Кнопка отправки неактивна пока чекбокс не отмечен
- Размер чекбокса: минимум 20x20px (touch target)

### Кнопка отправки

**Состояния:**

| Состояние | Внешний вид | Поведение |
|-----------|-------------|-----------|
| Default | Gold фон, белый текст | — |
| Hover | Тёмнее на 10% | Cursor pointer |
| Disabled | Grey фон, 50% opacity | Если чекбокс не отмечен или поля не заполнены |
| Loading | Spinner внутри кнопки, текст заменён на «Отправляем...» | Кнопка disabled, повторный клик заблокирован |
| Success | Зелёный чекмарк + текст «Готово!» | Через 2 сек → показать success state |
| Error | Красная обводка кнопки + текст ошибки под формой | Кнопка снова активна |

### Валидация

**Подход:** валидация при blur (потере фокуса), не при каждом нажатии клавиши.

**Сообщения об ошибках:**

| Поле | Ошибка | Сообщение |
|------|--------|-----------|
| Имя | Пустое | «Укажите ваше имя» |
| Телефон | Пустой | «Укажите номер телефона» |
| Телефон | Неполный | «Проверьте номер — не хватает цифр» |
| Чекбокс | Не отмечен | «Для отправки необходимо согласие на обработку данных» |

**Стилизация ошибок:**
- Красная обводка поля (border-color: #C44)
- Текст ошибки под полем, 12px, цвет #C44
- Иконка ошибки (!) слева от текста

## Состояния формы

### Success State (после отправки)

**Вариант для формы на странице:**
Форма плавно заменяется на:
```
✓ Заявка отправлена

Мы перезвоним в течение часа.
Если срочно — звоните: +7 843 223-66-66
или пишите в WhatsApp: +7 965 612-28-88
```

**Вариант для модалки:**
Форма заменяется → те же тексты → через 3 сек модалка закрывается автоматически.

### Error State (ошибка отправки)

```
Не удалось отправить заявку.
Позвоните нам напрямую: +7 843 223-66-66
```
Кнопка «Попробовать снова» — возвращает форму в рабочее состояние.

## Адаптация под мобайл

### Общее
- Поля занимают 100% ширины
- Высота полей: минимум 48px (touch target)
- Расстояние между полями: 12px
- Кнопка: 100% ширины, высота 52px
- Клавиатура не перекрывает активное поле (scroll into view)

### Телефон
- `inputmode="tel"` → цифровая клавиатура
- Маска работает с мобильным вводом

### Модалка на мобайле
- Full-screen bottom sheet (не центрированная модалка)
- Свайп вниз для закрытия
- Высота: auto (по содержимому)

### WhatsApp кнопка
- Фиксированная позиция: bottom 20px, right 20px
- Размер: 56x56px, зелёный фон (#25D366)
- Z-index выше модалки overlay (z-index: 200)
- Не показывать если открыта модалка записи

## Юридические требования (152-ФЗ)

- [ ] Чекбокс НЕ предзаполнен на каждой форме
- [ ] Текст чекбокса содержит ссылку на политику обработки ПД
- [ ] Политика обработки ПД загружается (PDF или отдельная страница /documents/)
- [ ] Данные хранятся на российском хостинге (Beget Cloud / Timeweb Cloud)
- [ ] При отправке формы данные НЕ уходят в зарубежные сервисы (Google Forms, Typeform и т.п.)
- [ ] Пациент может отозвать согласие (информация в политике)

## Куда уходят заявки

**Текущая система:** 1С УМЦ — не интегрируется с сайтом.

**Маршрут заявки:**
1. Пациент заполняет форму на сайте
2. Данные отправляются на email администратора (или Telegram-бот)
3. Администратор перезванивает и записывает в 1С вручную

**Реализация отправки (Astro 5):**
- Форма → POST на serverless-функцию
- Функция → отправка в Telegram-бот и/или email
- Fallback: если функция недоступна → показать телефон и WhatsApp

**Яндекс.Метрика — цели:**
- `form_submit_quick` — быстрая запись (тип A)
- `form_submit_inquiry` — задать вопрос (тип B)
- `form_submit_directed` — запись с направлением (тип C)
- `modal_open` — открытие модалки записи
- `whatsapp_click` — клик по WhatsApp
- `phone_click` — клик по телефону

## Визуальная спецификация

### Поле ввода

```
┌─────────────────────────────────────┐
│  Ваше имя                          │  ← placeholder, Inter 14px, muted color
└─────────────────────────────────────┘
   height: 48px
   padding: 14px 16px
   border: 1px solid var(--border)
   border-radius: 0 (straight edges — premium feel)
   background: transparent (cream section) или rgba(255,255,248,0.06) (dark section)
```

**Фокус:** border-color → var(--gold)
**Ошибка:** border-color → #C44, текст ошибки 12px под полем

### Кнопка

```
┌─────────────────────────────────────┐
│       Записаться на консультацию     │  ← Open Sans 13px, 500 weight, 0.05em spacing
└─────────────────────────────────────┘
   height: 52px (мобайл) / 48px (десктоп)
   background: var(--gold) #B8956A
   color: #fff
   border-radius: 0
   width: 100% (в формах) / auto (в hero)
```

### Чекбокс

```
☐ Соглашаюсь на обработку персональных данных
   ↑ 20x20px, border: 1px solid var(--border), border-radius: 2px
   accent-color: var(--gold) при checked
   label: 12px, muted color, ссылка подчёркнутая
```

## Чеклист проверки каждого фото

Перед тем как качать в `src/assets/photos/`:

- [ ] Нет улыбающихся людей в кадре (если люди — то edit-портрет, нейтральная мимика).
- [ ] Нет белых халатов, шприцов, медицинской атрибутики.
- [ ] Нет ярких цветов (только cream/champagne/warm grey палитра).
- [ ] Нет читаемых брендов на упаковке.
- [ ] Нет watermark / signature.
- [ ] Минимум 1620px по короткой стороне (для 2× retina на 810px слот).
- [ ] Лицензия совместима (Unsplash/Pexels — да; Cosmos.so/Pinterest — нет, только мудборд).
- [ ] EXIF чистый (без GPS) после скачивания.

## Workflow

1. Открыть нужный слот в этом доке.
2. Кликнуть 2-3 ссылки на Unsplash/Pexels.
3. Скачать 5-10 кандидатов в `~/Downloads/photo-candidates/<slot>/`.
4. Отсеять по чеклисту → оставить 2-3 лучших.
5. Применить LUT по [`treatment.md`](treatment.md).
6. Положить в `src/assets/photos/<slot>.jpg`.
7. Заменить `<ImagePlaceholder>` на `<Image>` в коде.

# PRD: Страница «Пластическая хирургия» — /plastika/

## Цель страницы

Посадочная для Яндекс.Директ + SEO-каталог всех пластических операций. Пациент приходит с запросом «пластическая хирургия казань» или «ринопластика казань» и должен: (1) понять что клиника выполняет его операцию, (2) увидеть цену, (3) записаться.

## Целевая аудитория

- **Сегмент 2 (35–55, возвращающая уверенность)** — основной поток
- **Сегмент 1 (28–40, профессиональный оптимизатор)** — блефаропластика, малоинвазивные
- **Сегмент 5 (30–55, мужчины)** — ринопластика, блефаропластика, липосакция

## Конверсионная цель

- **Основная:** «Записаться на консультацию» через форму на странице
- **Вторичная:** переход к конкретному врачу → запись к нему

## Структура страницы

### 1. Hero (400px, cream)
- **H1:** «Пластическая хирургия в Казани — клиника Platinental»
- **Lead:** 3 предложения — гармонизирующий подход, авторские методики, начинаем с замеров
- **CTA:** «Записаться на консультацию» + «Узнать стоимость»

### 2. Фильтр
Два таба: **Лицо** / **Тело** (переключение без перезагрузки)

### 3. Карточки операций (27 шт.)

**Лицо (14 шт.):** Блефаропластика, Подтяжка SMAS, Эндоскопическая подтяжка лба, Голливудская подтяжка шеи, Ринопластика, Отопластика, Ментопластика, Увеличение подбородка, Комки Биша, Булхорн, Липофилинг, Субцизия, Гармонизирующие операции, Гармонизация тела

**Тело (13 шт.):** Маммопластика, Мастопексия, Коррекция ареол, Гинекомастия, Абдоминопластика, Липосакция, Липомоделирование, Бразильский лифтинг ягодиц, Глютеопластика, Брахиопластика, Омоложение рук, Удаление рубцов

**Карточка содержит:**
- Название операции (H3)
- 1 предложение: конкретный результат для пациента (не медицинское определение)
- Цена: «от X ₽» (из prices.md)
- CTA: «Подробнее» или «Записаться»
- Фото-плейсхолдер (до реальных фото)

### 4. Блок «Хирурги направления» (6 карточек)
Мини-карточки хирургов: фото, ФИО, ключевая специализация, «от X ₽ консультация»

### 5. Принципы клиники (кратко)
3 буллита: авторские методики / начинаем с замеров / американский бренд

### 6. FAQ (5–7 вопросов)
Вопросы о пластике: реабилитация, возрастные ограничения, анестезия, повторные операции, выбор хирурга

### 7. Форма записи + дисклеймер

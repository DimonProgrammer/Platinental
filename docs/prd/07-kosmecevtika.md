# PRD: Страница «Космецевтика» — /kosmecevtika/

## Цель страницы

Каталог профессиональной косметики. Не e-commerce: нет корзины, нет оплаты. Цель — показать ассортимент и записать на подбор с косметологом. Космецевтика дополняет хирургию и косметологию: реабилитация, поддержание результата, ежедневный уход.

## Целевая аудитория

- **Сегмент 3 (24–35)** — ищет профессиональный уход как часть рутины
- **Сегмент 2 (35–55)** — космецевтика после операции или процедуры (реабилитация)
- Пациенты клиники, которые уже прошли процедуру

## Конверсионная цель

- **Основная:** «Записаться на подбор» (не «Купить»)
- **Вторичная:** знакомство с ассортиментом → доверие → запись на основную процедуру

## Структура страницы

### 1. Hero (300px, cream)
- **H1:** «Космецевтика в Казани — профессиональная косметика Platinental»
- **Lead:** 2 предложения — подбор косметики по задаче, не из каталога, а с косметологом

### 2. Фильтр (опционально)
По назначению: Реабилитация / Анти-эйдж / Ежедневный уход / Защита
(Если товаров мало — без фильтра, просто сетка)

### 3. Карточки товаров
**Карточка содержит:**
- Фото (плейсхолдер)
- Название
- Краткое описание (1 предложение — для чего)
- Цена
- CTA: «Подробнее» (раскрытие) — не «Купить»

### 4. CTA-блок
«Записаться на подбор косметики — консультация 2 000 ₽»
Форма: Имя, Телефон, Чекбокс 152-ФЗ

### 5. Дисклеймер

## Дизайн-заметки

- Карточки товаров: меньше чем карточки услуг (3-4 в ряд)

- Акцент на CTA «Записаться на подбор», не на цены товаров

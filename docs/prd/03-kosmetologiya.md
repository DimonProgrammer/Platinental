# PRD: Страница «Косметология» — /kosmetologiya/

## Цель страницы

Каталог всех косметологических процедур + посадочная для Директа. Аудитория шире и моложе чем пластика — включает преджювенацию (25–35). Барьер входа ниже: процедуры дешевле, без операции, минимальный даунтайм.

## Целевая аудитория

- **Сегмент 3 (24–35, эстетический перфекционист)** — ботокс, контурная пластика, губы
- **Сегмент 1 (28–40, профессиональный оптимизатор)** — ботокс, биоревитализация, без даунтайма
- **Сегмент 2 (35–55, возвращающая уверенность)** — лазер, филлеры, аппаратные

## Конверсионная цель

- **Основная:** запись на консультацию к косметологу (Грицай О.А., от 2 000 ₽)
- **Вторичная:** переход к конкретной процедуре → понимание цены → запись

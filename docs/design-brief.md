# Дизайн-бриф для Максима

## Общее видение

Премиальный медицинский сайт с маркетинговым фокусом. Не просто информационный ресурс, а конверсионная машина под Яндекс Директ. Стиль: "дорогое ателье", а не "поликлиника".

Ключевое ощущение: **доверие + экспертиза + доступность записи**.

## Референсы

### 1. buharova.com/clinics/chistopolskaya/

**Что взять:**
- Сетка карточек услуг с крупными изображениями
- Multi-channel CTA: телефон, чат, Telegram, запись онлайн
- Прозрачные часы работы и адрес в sticky-хедере
- Лаконичная навигация

**Что не брать:**
- Слишком большое меню (70+ пунктов)
- Отсутствие фото врачей на главной

### 2. iphk.ru/department/plasticheskaya-khirurgiya/

**Что взять:**
- До/после галереи (фото + видео) на страницах услуг
- Карточки врачей с учёными степенями и специализацией
- Номер лицензии на каждой странице
- Хлебные крошки
- Перекрёстные ссылки между связанными услугами

**Что не брать:**
- Институциональный холодный тон
- Отсутствие цен на страницах услуг

### 3. platinental.ru (головной сайт)

**Что взять:**
- Брендовый стиль, ощущение премиума
- Философия "интеллигентной гармонизации" в текстах
- Тёмные hero-секции с качественными фото

**Что не брать:**
- Московскую специфику (адреса, врачи, оборудование)

## Must-have элементы

### Глобальные (на каждой странице)

- Sticky header: логотип, телефон (+7 843 223-66-66), кнопка "Записаться"
- Плавающая кнопка WhatsApp (+7 965 612-28-88) — mobile
- Футер: навигация, лицензия, 152-ФЗ ссылки, соцсети
- Дисклеймер: "Имеются противопоказания, требуется консультация специалиста"
- Mobile-first: все макеты сначала мобильные, потом десктоп

### Главная страница

- Hero-секция с сильным оффером + CTA + счётчики (20+ лет, 10+ патентов)
- 3 карточки направлений (Пластика / Косметология / Космецевтика)
- Карусель врачей с фото
- Галерея до/после
- Слайдер отзывов
- Форма-лидмагнит ("Бесплатная онлайн-консультация")
- FAQ-блок (аккордеон)

### Страница услуги

- Hero с названием + кратким описанием
- Блок "Показания" (для кого)
- Как проходит процедура (этапы)
- До/после фото
- Врачи, выполняющие процедуру
- Цена "от X руб." + CTA "Записаться"
- FAQ (5-7 вопросов)
- Блок связанных услуг

### Карточка врача

- Профессиональный портрет
- ФИО, специализация, учёная степень
- Ключевые операции / процедуры
- Стоимость консультации
- Кнопка "Записаться к этому врачу"

### Каталог космецевтики

- Сетка карточек товаров
- Фильтр по типу кожи / проблеме (если товаров достаточно)
- Каждая карточка: фото, название, описание, цена
- CTA: "Записаться на подбор" (не "Купить")

## Запрещено

- Стоковые фото (особенно улыбающиеся модели с белыми зубами)
- E-commerce с корзиной и оплатой (только каталог)
- Перегруженные макеты с 5+ блоками в ряд
- Анимации ради анимаций (микроанимации — ок, если уместны)
- Больше 1 попапа на странице
- Автозвук / автовидео

## Формы

Каждая форма — минимум полей для снижения трения:

| Форма | Поля | CTA-текст |
| --- | --- | --- |
| Запись на консультацию | Имя, телефон, чекбокс ПД | "Записаться" |
| Онлайн-консультация | Имя, телефон, фото (опц.), чекбокс ПД | "Получить консультацию" |
| Обратный звонок | Телефон, чекбокс ПД | "Перезвоните мне" |
| Вопрос врачу | Имя, телефон, текст вопроса, чекбокс ПД | "Отправить вопрос" |

152-ФЗ: чекбокс согласия обязателен на каждой форме.

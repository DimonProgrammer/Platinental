# Архитектура сайта Platinental Казань

## Общая структура

Одностраничный лендинг с якорными секциями + внутренние страницы для услуг, врачей, цен.
Фокус: конверсия из Яндекс Директ, SEO по услугам, доверие через экспертизу.

---

## Основные страницы (7)

### 1. Главная `/`

Посадочная страница-витрина. Структура секций:

| # | Секция | Назначение |
| --- | --- | --- |
| 1 | Hero | Заголовок + подзаголовок + CTA "Записаться" + соц. доказательство (20+ лет, 10+ патентов, 8 врачей) |
| 2 | Преимущества | 3-4 карточки: индивидуальный подход, авторские методики, естественный результат, реабилитация |
| 3 | Направления | 3 карточки-ссылки: Пластика, Косметология, Космецевтика |
| 4 | Популярные услуги | 6-8 карточек топ-услуг с ценой "от X руб." |
| 5 | Врачи | Карусель/сетка врачей с фото, именем, специализацией |
| 6 | До/После | Галерея результатов (фото + видео) |
| 7 | Отзывы | Слайдер отзывов пациентов |

| 9 | Лидмагнит | Форма "Бесплатная онлайн-консультация" / "Получить план лечения" |

| 11 | Контакты | Адрес, телефон, карта, WhatsApp, график работы |
| 12 | Футер | Навигация, документы, политика ПД, лицензия, соцсети |

**CTA-стратегия на главной:**

## SEO-требования

Каждая страница:
- Уникальный `<title>` с гео "Казань" (60-70 символов)
- Уникальный `<meta description>` (150-160 символов)
- `<h1>` — один на страницу
- Schema.org: `MedicalClinic`, `Physician`, `MedicalProcedure`, `Product` (космецевтика)
- Хлебные крошки (`BreadcrumbList`)
- Alt-теги на всех изображениях
- Семантическая вёрстка (`<article>`, `<section>`, `<nav>`)
- Скорость загрузки < 3 сек (Core Web Vitals)
- Мобильная версия (responsive, mobile-first)

---

## Юридические требования

- Чекбокс согласия на обработку ПД на каждой форме (152-ФЗ)
- Политика конфиденциальности — ссылка в футере
- Дисклеймер "Имеются противопоказания, требуется консультация специалиста"
- Номер лицензии на каждой странице (футер)
- Цены не являются публичной офертой — дисклеймер
- Версия для слабовидящих (желательно)
- Хостинг на территории РФ

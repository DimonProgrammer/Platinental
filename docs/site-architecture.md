# Архитектура сайта Platinental Казань

## Общая структура

Одностраничный лендинг с якорными секциями + внутренние страницы для услуг, врачей, цен.
Фокус: конверсия из Яндекс Директ, SEO по услугам, доверие через экспертизу.

### 3. Услуги

Три хаб-страницы. Отдельных страниц под каждую услугу нет.
После запуска — по данным Метрики добавить отдельные страницы для топ-услуг (Директ).

#### 3.1 Пластика `/plastika/`

Полноценная страница-каталог. Структура:
- Hero: заголовок + краткое описание направления + CTA
- Дисклеймер (38-ФЗ) — видимо
- Фильтр по группам: Лицо / Тело / Реконструкция
- Карточки услуг (сетка): название, краткое описание, цена "от X ₽", кнопка "Записаться"
- Блок врачей-хирургов
- Форма записи
- FAQ (общие вопросы по пластике)

**Список услуг (все отображаются как карточки):**

Лицо: Блефаропластика, Подтяжка SMAS, Эндоскопическая подтяжка лба, Подтяжка шеи, Ринопластика, Отопластика, Ментопластика, Увеличение подбородка, Комки Биша, Булхорн, Липофилинг, Субцизия, Гармонизирующие операции, Гармонизация тела

Тело: Маммопластика, Увеличение груди, Мастопексия, Коррекция ареол, Коррекция гинекомастии, Абдоминопластика, Липосакция, Липомоделирование, Бразильский лифтинг ягодиц, Глютеопластика, Брахиопластика, Омоложение рук, Удаление рубцов

#### 3.2 Косметология `/kosmetologiya/`

Аналогичная структура. Фильтр: Инъекционная / Аппаратная / Терапевтическая.

Инъекционная: Ботокс, Мезоботокс, Биоревитализация, Контурная пластика (+ Radiesse, Volbella, Ekvio, гибкими канюлями), Увеличение губ, Плазмотерапия, Липотерапия, Мезотерапия Laennec, Мезотерапия Sakura, Коллагеновые инъекции, Sculptra, V-Lift, Novacutan, RegenLab

Терапевтическая: Маски, Пилинги, Лечение рубцов, Чистка лица, Уходовые процедуры

Аппаратная: Лазерная шлифовка, HELEO4, Эпиляция MiDEPi, Лимфодренаж, Лечение гипергидроза

#### 3.3 Космецевтика `/kosmecevtika/`

Каталог товаров — карточки.
Каждая карточка: фото, название, краткое описание, цена, кнопка "Подробнее" (модалка или раскрытие).
Без корзины и оплаты. CTA: "Записаться на подбор".

> Количество позиций: 20–30 (уточнить у клиента, нужен список с ценами).

## SEO-требования

Каждая страница:
- Уникальный `<title>` с гео "Казань" (60-70 символов)
- Уникальный `<meta description>` (150-160 символов)
- `<h1>` — один на страницу
- Schema.org: `MedicalClinic`, `Physician`, `MedicalProcedure`, `Product` (космецевтика)
- Хлебные крошки (`BreadcrumbList`)
- Alt-теги на всех изображениях
- Семантическая вёрстка (`<article>`, `<section>`, `<nav>`)
- Скорость загрузки < 3 сек (Core Web Vitals)
- Мобильная версия (responsive, mobile-first)

---

## Юридические требования

- Чекбокс согласия на обработку ПД на каждой форме (152-ФЗ)
- Политика конфиденциальности — ссылка в футере
- Дисклеймер "Имеются противопоказания, требуется консультация специалиста"
- Номер лицензии на каждой странице (футер)
- Цены не являются публичной офертой — дисклеймер
- Версия для слабовидящих (желательно)
- Хостинг на территории РФ
- HTTPS/SSL — обязательно для сайта, собирающего персональные данные
- Кастомная 404-страница с навигацией и CTA (важно для трафика из Директ)

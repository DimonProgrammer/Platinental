# Система копирайтинга — Платиненталь Казань

Документ для генерации текстов через AI. Используется совместно с `docs/content-rules.md`.

---

## 1. Философия: Информационный стиль

Основа — школа Максима Ильяхова (Главред).

**Пять законов:**
1. **Ясность** — незнакомый человек понимает с первого раза
2. **Краткость** — каждое слово добавляет информацию
3. **Структура** — главное первым, детали следом
4. **Конкретика** — факты вместо прилагательных
5. **Уважение** — не манипулировать, не запугивать, не льстить

**Синтаксис:**
- Предложение: 12–18 слов (среднее)
- Ритм: короткое (8) → среднее (15) → длинное (25) → короткое (6)
- Залог: активный. "Хирург работает с 13 параметрами", не "параметры учитываются хирургом"
- Абзацы: 2–4 предложения. Один абзац — одна мысль.

## 2. Чёрный список (расширенный)

### Маркетинговые пустышки
| Нельзя | Почему | Заменить на |
|--------|--------|-------------|
| Индивидуальный подход | Все так пишут | "Хирург подбирает методику по 13 антропометрическим стандартам" |
| Команда профессионалов | Ничего не значит | "6 пластических хирургов, средний стаж 11 лет" |
| Инновационные технологии | Абстракция | Назвать конкретно: "CO2-лазер SmartXide", "SMAS-лифтинг Ulthera" |
| Широкий спектр услуг | Канцелярит | Перечислить: "пластика, косметология, космецевтика" |
| Высокое качество | Не проверить | "98% пациентов не требуют повторной коррекции" |
| Лучшие специалисты | Запрещено 38-ФЗ без доказательств | Конкретные достижения врача |
| Доступные цены | Не для премиума | "Прозрачное ценообразование: от X ₽" |
| Гарантируем результат | Запрещено 323-ФЗ | "По нашему опыту..." или убрать |
| Безопасный метод | Без оговорок нельзя | "...при отсутствии противопоказаний" |
| Мечта всей жизни | Манипуляция | Убрать |
| Вы будете неотразимы | Обещание, нельзя | "Результат выглядит естественно" |
| Ваша красота — наша забота | Рекламный штамп | Убрать |
| Мы рады видеть вас | Дежурная фраза | Убрать |

### AI-маркеры (признаки ChatGPT/Claude без редактуры)
| Нельзя | Тип ошибки |
|--------|-----------|
| "Стоит отметить, что..." | Вводный паразит |
| "Следует понимать..." | Снисходительный тон |
| "В настоящее время..." | Временной штамп |
| "Как известно..." | Лекционный стиль |
| "В целом..." | Размытый вывод |
| "Во-первых... во-вторых... в-третьих..." | Шаблонный список |
| "Именно поэтому..." | Лишний акцент |
| "Таким образом..." | Формальный коннектор |
| "Можно сказать, что..." | Хеджирование |
| "Имеет смысл отметить..." | Тяжеловесно |
| "Благодаря [многократно]" | Повтор коннектора |
| "Поскольку [многократно]" | Повтор союза |
| Три симметричных пункта с параллельной структурой | AI-паттерн списка |
| Идеально правильные предложения без вариации длины | AI-ритм |

### Юридически запрещено (38-ФЗ, 323-ФЗ)
- Гарантии результата лечения
- Супerlative без доказательств ("лучшая клиника")  
- Запугивание ("без процедуры вы будете выглядеть...")
- Слово "безопасный" без оговорки "при отсутствии противопоказаний"

## 3. Промпты по типам текста

### 3.1 HERO-ЗАГОЛОВОК (главная страница)

**Когда использовать:** Hero-секция главной страницы, крупный H1.  
**Целевой сегмент:** Сегмент 2 (Возвращающая уверенность) как самый массовый.

**Промпт:**
```
Задача: написать hero-заголовок и подзаголовок для главной страницы клиники пластической хирургии и косметологии Платиненталь (Казань).

Данные клиники:
- 20+ лет бренд Платиненталь (московские корни)
- 6 пластических хирургов, 1 косметолог
- Три направления: пластика, косметология, космецевтика
- Премиум-сегмент, аудитория 25–55 лет
- Адрес: Карла Маркса, 48, Казань

Требования:
- Заголовок: 5–8 слов, конкретная обещанная ценность
- Подзаголовок: 15–25 слов, раскрывает заголовок
- Тон: уверенный врач-эксперт, не рекламная тональность
- Акцент: натуральный результат, не "сделанное" лицо
- НЕ использовать: "инновационные технологии", "команда профессионалов", "ваша красота наша забота", превосходные степени без доказательств
- Информационный стиль: конкретика, активный залог
- Объём: 3–5 вариантов заголовка + подзаголовок к каждому

Дисклеймер обязателен: "Имеются противопоказания. Необходима консультация специалиста."
```

**Пример хорошего результата:**
> **Заголовок:** Эстетическая медицина без лишнего  
> **Подзаголовок:** Шесть хирургов с авторскими методиками. Результаты, которые выглядят как вы — только лучше.

**Пример плохого результата (запрещён):**
> ~~Мы — лидеры красоты Казани! Команда профессионалов с инновационными технологиями поможет вам стать неотразимой!~~

### 3.2 LEAD-АБЗАЦ СТРАНИЦЫ УСЛУГИ

**Когда использовать:** Первые 2–3 предложения на странице услуги, сразу после H1.  
**Цель:** Ответить на вопрос "что это и для кого" за 30 секунд.

**Промпт:**
```
Задача: написать вводный абзац (lead) для страницы услуги [НАЗВАНИЕ УСЛУГИ] на сайте клиники Платиненталь (Казань).

Данные процедуры:
- [Что это за процедура: 1 предложение]
- [Для кого: целевой сегмент из audience-jtbd.md]
- [Ключевой результат: что конкретно происходит]
- [Срок/время: длительность процедуры и реабилитация]
- [Цена: от X ₽]

Структура абзаца:
1. Что это — без определений из медицинского словаря (12 слов)
2. Кому подойдёт — конкретная ситуация пациента, не "широкому кругу лиц" (20 слов)
3. Ключевой результат — что изменится после процедуры (15 слов)

Требования:
- Избегать: "данная процедура", "современный метод", "индивидуальный подход"
- Активный залог, предложения 12–18 слов
- Никаких гарантий результата
- Обязателен дисклеймер в конце раздела: "Имеются противопоказания. Необходима консультация специалиста."
```

**Пример (блефаропластика, Сегмент 1 + 2):**
> Блефаропластика убирает нависание кожи верхних век и "мешки" под глазами. Подходит, когда взгляд выглядит усталым на деловых встречах и фото — даже после отдыха. Результат держится 7–10 лет.

### 3.3 ЗАГОЛОВОК H1 (страница услуги)

**Требование:** H1 должен содержать ключевой запрос + "Казань" там, где органично.  
**Формула:** `[Название процедуры] в Казани` или `[Процедура]: [конкретный результат]`

**Промпт:**
```
Задача: написать H1 для страницы [УСЛУГА] клиники Платиненталь Казань.

SEO-требования: ключевой запрос "[услуга] казань" или "[услуга] казань цена" должен быть в H1.
Длина: 4–8 слов.
Тон: нейтральный медицинский, не рекламный.

Дополнительно: предложить 3 варианта H1 — один точный (SEO), один описательный, один с результатом.
```

**Примеры:**
- `Блефаропластика в Казани` — точный SEO
- `Коррекция век — операция за 40 минут` — описательный
- `Убрать нависание век. Казань, Платиненталь` — с результатом

### 3.4 БЛОК ПОКАЗАНИЙ

**Когда использовать:** Раздел "Кому подойдёт" или "Показания" на странице услуги.  
**Цель:** Читатель узнаёт себя в списке и понимает, что это для него.

**Промпт:**
```
Задача: написать список показаний для [УСЛУГА] в формате "Вам подойдёт процедура, если..."

Аудитория: [сегменты из audience-jtbd.md, применимые к данной услуге].

Правила:
- 5–7 пунктов маркированного списка
- Каждый пункт — конкретная ситуация, не медицинский диагноз
- Начинать с узнаваемой бытовой ситуации
- Не использовать медицинские термины без расшифровки
- Тон: описательный, не оценочный ("у вас нависание кожи" — нейтрально, не "вы выглядите старо")

Пример для блефаропластики:
- Кожа верхних век нависает и визуально сужает взгляд
- Под глазами постоянно видны "мешки", независимо от сна
- Взгляд выглядит усталым или хмурым на фото и видео
```

### 3.5 КАК ПРОХОДИТ ПРОЦЕДУРА

**Когда использовать:** Раздел "Этапы" или "Как это работает" на странице услуги.  
**Цель:** Снять тревогу перед процедурой, показать контроль и предсказуемость.

**Промпт:**
```
Задача: написать пошаговое описание процедуры [УСЛУГА].

Целевая работа: снять страх неизвестности. Читатель должен чётко представить, что произойдёт от первого контакта до финального результата.

Структура:
1. До (консультация, подготовка)
2. В день процедуры (что происходит в клинике)
3. Сама процедура (этапы, ощущения, длительность)
4. После (что делать, чего ждать, когда придёт результат)

Требования:
- Каждый шаг: 1–2 предложения
- Включить: длительность каждого этапа
- Тон: спокойный, будничный (не "уникальная инновация"), как рассказывает опытный врач пациенту перед операцией
- Не использовать пассивный залог
- Реабилитация: реальные сроки, не "в кратчайшие сроки"
```

### 3.6 FAQ (5–7 вопросов)

**Когда использовать:** FAQ-блок в конце страницы услуги.  
**Цель:** SEO (структурированные данные FAQPage) + снятие возражений.

**Промпт:**
```
Задача: написать 6 вопросов и ответов FAQ для страницы [УСЛУГА].

Источник вопросов: типичные страхи и сомнения сегментов [указать] из audience-jtbd.md.
Ключевые страхи для данной услуги: [перечислить из файла аудитории].

Правила:
- Вопрос формулировать как реальный пациент, не как маркетолог
  ❌ "Каковы преимущества данной процедуры?"
  ✅ "Будет ли видно, что я что-то делала?"
- Ответ: 3–5 предложений. Конкретный факт, затем объяснение, затем реалистичный прогноз.
- Не обещать стопроцентный результат
- Не игнорировать риски: упомянуть и нормализовать ("у большинства пациентов...")
- Один вопрос обязательно про цену или восстановление

Schema.org-разметка: FAQPage с mainEntity/Question/acceptedAnswer.
```

**Пример вопроса и ответа (блефаропластика):**
> **Q: Будет ли заметно, что я делала операцию?**  
> А: Послеоперационный отёк спадает за 7–14 дней. Швы снимают на 5–7 день, следы от них становятся невидимы через 2–4 недели. Большинство пациентов возвращается к работе через 10–14 дней. Финальный результат виден через 3–6 месяцев.

### 3.7 КАРТОЧКА ВРАЧА (краткая)

**Когда использовать:** Карточка в сетке на странице /doctors/ или в блоке "Врачи" на главной.

**Промпт:**
```
Задача: написать описание врача для карточки (карусель/сетка).

Данные:
- ФИО: [имя]
- Специализация: [из site-architecture.md]
- Стаж: [данные от клиента — не придумывать]
- Ключевые операции/процедуры: [данные от клиента]

Ограничения:
- Длина: 2–3 предложения
- Стиль: конкретный, без "опытный специалист" и "высококвалифицированный"
- Первое предложение: факты (стаж + специализация)
- Второе: что конкретно делает лучше всего
- НИКОГДА не придумывать данные — только то, что предоставил клиент

Формат:
ФИО | Специализация
[2–3 предложения]
Консультация: от X ₽ | [Кнопка: Записаться]
```

### 3.9 CTA-ТЕКСТЫ

**Матрица CTA по сегментам:**

| Сегмент | CTA-текст | Лидмагнит |
|---------|----------|-----------|
| Профессиональный оптимизатор | "Записаться" / "Консультация за 20 мин" | "Расчёт плана без операции" |
| Возвращающая уверенность | "Получить план омоложения" / "Записаться на диагностику" | "Бесплатная онлайн-консультация по фото" |
| Эстетический перфекционист | "Записаться к врачу" / "Записаться к пятнице" | "Результат к мероприятию — узнать срок" |
| Здоровье + эстетика | "Записаться на консультацию" | "Медицинская консультация — оценить показания" |

**Запрещённые CTA:**
- "Узнать больше" — слишком общий
- "Нажмите сюда" — устаревший паттерн  
- "Успейте записаться!" — создаёт дефицит (не для премиума)
- "Запишитесь прямо сейчас, пока есть скидка!!!" — прямо из антиклише

### 3.10 БЛОК ПРЕИМУЩЕСТВ (главная)

**Когда использовать:** Секция #2 главной страницы — 3–4 карточки преимуществ.

**Промпт:**
```
Задача: написать 4 преимущества Платиненталь для главной страницы.

Реальные данные (подтверждены):
- Бренд Платиненталь: 20+ лет, московские корни, РНИМУ Пирогова
- Врачи: 6 хирургов + 1 косметолог
- Три направления: пластика, косметология, космецевтика
- Нет: данных по количеству операций, наградам — не придумывать

Структура каждой карточки:
- Иконка/эмодзи: 1 символ (тема)
- Заголовок: 3–5 слов — конкретный факт, не прилагательное
- Описание: 2–3 предложения

Требования:
- НЕ использовать "индивидуальный подход", "высокое качество", "современное оборудование"
- Каждое преимущество должно быть проверяемым или конкретным
- Конкурентные преимущества: связать с positioning gap из competitors-*.md
```

**Пример:**
> 🔬 **Авторские методики, не шаблоны**  
> Хирурги Платиненталь разработали собственные протоколы гармонизации — результат не выглядит стандартным. Методика подбирается индивидуально, а не из прайс-листа.

## 7. Чеклист перед публикацией

Перед публикацией любого текста проверить:

- [ ] Нет ни одного слова из чёрного списка (раздел 2)
- [ ] Активный залог (нет "является", "осуществляется", "проводится")
- [ ] Конкретные числа/факты вместо прилагательных
- [ ] Предложения 12–18 слов (среднее), есть ритм (короткие + длинные)
- [ ] Нет гарантий результата (323-ФЗ)
- [ ] Нет супerlative без доказательств (38-ФЗ)
- [ ] Дисклеймер о противопоказаниях есть и виден
- [ ] Данные о врачах, ценах, адресах — из первичных источников, не придуманы
- [ ] Meta description 150–160 символов
- [ ] H1 = ключевой запрос + "Казань" (для SEO-страниц)

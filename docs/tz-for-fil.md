# ТЗ на разработку сайта — Platinental Казань

Версия: 1.0 · Дата: апрель 2026 · Статус: **на согласовании**

---

## 1. Цель проекта

Пересборка сайта kzn.platinental.ru с нуля.

**Проблема текущего сайта:**
- WordPress — медленный, устаревший дизайн
- Не адаптирован под трафик из Яндекс Директ
- Не соответствует премиум-позиционированию бренда
- Нет чётких посадочных страниц под рекламные кампании

**Результат:**
- Быстрый статический сайт (95+ Lighthouse)
- Конверсионные страницы под Яндекс Директ
- Структура под SEO (55+ страниц услуг, schema.org)
- Соответствие 38-ФЗ, 152-ФЗ, 323-ФЗ

## 3. Технический стек

| Компонент | Решение | Обоснование |
|-----------|---------|-------------|
| Фреймворк | **Astro 5** | 0 KB JS по умолчанию, 95+ Lighthouse, идеален для контентных сайтов |
| Стили | **TailwindCSS v4** | Отраслевой стандарт, минимальный CSS-бандл |
| Язык | TypeScript | Надёжность кода |
| Аналитика | Яндекс.Метрика (`astro-ym`) | Нативная поддержка, цели под Директ |
| Хостинг | **Beget Cloud** или Timeweb Cloud | Российский ЦОД, 152-ФЗ, UZ-1 сертификат |
| CMS | CloudCannon (опц.) | Git-based, если потребуется редактор для клиента |

**Почему не Next.js:** сайт на 90% контент + формы. Astro даёт страницы ~50 KB против 400+ KB у Next.js. Для медицинского сайта с трафиком из Директ это прямо влияет на конверсию.

## 4. Структура сайта

```
/                          Главная (12 секций)
/about/                    О клинике
/plastika/                 Пластика — каталог всех операций (карточки + цены + CTA)
/kosmetologiya/            Косметология — каталог процедур (карточки + цены + CTA)
/kosmecevtika/             Космецевтика — каталог товаров (карточки, без оплаты)
/prices/                   Прайс-лист (таблица, ~60 позиций)
/doctors/                  Карточки врачей (8 специалистов)
/documents/                Лицензии, политика ПД
/contacts/                 Адрес, телефон, карта
/404                       Кастомная 404
```

**Итого: 10 страниц.** Отдельных страниц под каждую услугу нет.

> Яндекс.Директ ведёт на хаб-страницу направления (/plastika/, /kosmetologiya/).
> После запуска: по данным Метрики добавить 3–5 лендингов для топ-услуг.

## 8. SEO

- Каждая страница: уникальный `<title>` + `<meta description>` + `<h1>`
- Шаблон title: `[Услуга] в Казани — Клиника Platinental | Цена от X руб.`
- Schema.org: `MedicalClinic`, `Physician`, `MedicalProcedure`, `Product`, `FAQPage`, `BreadcrumbList`
- Geo: слово "Казань" в title, H1 и первом абзаце каждой страницы услуги
- Скорость: Core Web Vitals (LCP < 2.5s, CLS < 0.1, INP < 200ms)

## 11. Открытые вопросы (нужны ответы для старта)

### 🔴 Блокируют дизайн
1. **Акцентный цвет** — клиент сказал "не красный", но конкретный вариант не выбран. Нужно предложить 2–3 варианта и согласовать. Кандидаты: тёмное золото `#B8956A`, шампань `#C4A882`, мягкое бордо `#7A2332`.
2. **Фотосессия врачей** — фото нет. Без них сайт не выглядит премиально. Контакт: @aleksa_chernyshova.

### 🟡 Нужны до разработки
3. **Актуальные цены** — прайс на сайте устаревший. Нужен Excel/PDF от клиента.
4. **Количество позиций космецевтики** — клиент сказал "20–30". Нужен конкретный список с названиями и ценами.
5. **Слоган / философский текст** — клиент сказал "подумаем". Нужен до контентной разработки.
6. **Выбор хостинга** — Beget или Timeweb? Кто регистрирует и оплачивает?

### 🟢 Можно решить позже
7. **Раздел "Акции"** — добавлять или нет? Клиент не подтвердил.
8. **CloudCannon (CMS)** — нужен ли клиенту самостоятельный редактор контента?
9. **Рассрочка** — есть ли рассрочка/кредит? Это важный конверсионный элемент.

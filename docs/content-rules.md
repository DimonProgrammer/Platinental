# Правила контента — Platinental Казань

## Язык и тон

**Язык:** русский. Латиница допускается только в названиях брендов и процедур (SMAS, Sculptra, Radiesse, MiDEPi).

**Тон:** экспертный, уверенный, но не высокомерный. Премиальный, но доступный. Как разговор с опытным врачом, который уважает пациента.

| "Результат выглядит естественно" | "Вы будете неотразимы" |

## Юридические требования к контенту

### Обязательные дисклеймеры

На каждой странице с описанием медицинских услуг:
> Имеются противопоказания. Необходима консультация специалиста.

На страницах с ценами:
> Цены носят информационный характер и не являются публичной офертой. Точную стоимость определяет врач на консультации.

На страницах с фото до/после:
> Результат индивидуален и зависит от особенностей организма.

### Запреты (38-ФЗ "О рекламе", ст. 24; 323-ФЗ)

**Общие запреты:**

- **Нельзя** гарантировать результат лечения
- **Нельзя** использовать фото до/после без согласия пациента
- **Нельзя** ссылаться на конкретных пациентов (даже с согласия) без пометки "Результат индивидуален"
- **Нельзя** создавать впечатление, что без процедуры будет плохо (запрет запугивания)
- **Нельзя** утверждать безопасность без оговорок
- **Нельзя** использовать слово "безопасный" без контекста "при соблюдении рекомендаций врача"
- **Нельзя** использовать образы медработников для рекламы конкретных процедур (ст. 24, п. 4)

**Обязательные элементы в рекламе медуслуг (38-ФЗ, ст. 24):**

- Предупреждение: "Имеются противопоказания. Необходима консультация специалиста" — **крупно, заметно**, не мелким шрифтом
- Наименование медицинской организации: ООО "Платинентал Казань"
- Номер лицензии — в рекламных материалах и на посадочных страницах Яндекс Директ
- Адрес клиники

**Посадочные страницы Яндекс Директ (дополнительно):**

- Дисклеймер о противопоказаниях — в видимой части экрана, не только в футере
- Лицензия + наименование юрлица — на каждой посадочной
- Соответствие текста посадочной рекламному объявлению (Яндекс проверяет релевантность)
- Запрет использования превосходных степеней без подтверждения ("лучшая клиника") — ст. 5, п. 1

## Источники контента

### Откуда брать

1. **kzn.platinental.ru** — текущий сайт. Парсить: имена врачей, цены, описания услуг. Улучшать через AI
2. **platinental.ru** — головной сайт. Брать: философию бренда, методологию, описания процедур. НЕ брать московскую специфику
3. **Клиент** — подтверждение: актуальные цены, новые врачи, акции, фото
4. **AI-генерация** — дописывать описания услуг, FAQ, SEO-тексты. Всегда проверять факты

### Чего НИКОГДА не выдумывать

- Имена и фамилии врачей
- Учёные степени и сертификаты
- Цены на услуги
- Адрес и контакты клиники
- Фото до/после
- Отзывы пациентов
- Номера лицензий и документов
- Статистику операций ("5000+ операций") — только если подтверждено клиентом

## SEO-правила

### Title (60-70 символов)

Шаблон: `[Услуга] в Казани — Клиника Platinental | Цена от [X] руб.`

Примеры:
- "Ринопластика в Казани — Клиника Platinental | Цена от 200 000 руб."
- "Маммопластика в Казани — Увеличение груди | Platinental"
- "Ботокс в Казани — Инъекции ботулотоксина | Platinental"

### Meta Description (150-160 символов)

Шаблон: `[Краткое описание услуги] в клинике Platinental Казань. [Преимущество]. Запись: +7 (843) 223-66-66.`

### H1

Один на страницу. Содержит ключевой запрос + гео "Казань" (где уместно).

### Schema.org

| Тип страницы | Schema |
| --- | --- |
| Главная | `MedicalClinic` |
| Врач | `Physician` |
| Услуга | `MedicalProcedure` |
| Космецевтика | `Product` |
| Цены | `PriceSpecification` |
| FAQ | `FAQPage` |
| Хлебные крошки | `BreadcrumbList` |

### Гео-привязка

Каждая страница услуги должна содержать слово "Казань" или "в Казани" хотя бы в:
- Title
- H1 или первом абзаце
- Meta description

## Структура текста на странице услуги

1. **Заголовок H1** — название процедуры + гео
2. **Лид-абзац** (2-3 предложения) — что это, для кого, ключевой результат
3. **Показания** — маркированный список
4. **Как проходит** — пошаговое описание или таблица
5. **Результат** — что ожидать, сроки реабилитации
6. **Врачи** — кто выполняет
7. **Цена** — "от X руб."
8. **FAQ** — 5-7 вопросов (SEO + снятие возражений)
9. **CTA** — форма записи

Оптимальная длина: 800-1500 слов на страницу услуги.

## Обращение к читателю

- "Вы" с заглавной буквы (формат уважительного обращения)
- Не использовать "ты"
- Не использовать "девушки", "женщины" в контексте ЦА — писать нейтрально
- Допустимо: "пациент", "пациентка" (в контексте описания процедуры)
